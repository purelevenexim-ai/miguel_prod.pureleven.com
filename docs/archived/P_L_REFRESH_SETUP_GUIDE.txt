THE ISSUE YOU HAD:
─────────────────
  ✗ You marked 1 order as "delivered"
  ✗ Went to P&L dashboard
  ✗ Still shows ₹0 revenue
  ✗ "Why isn't it updating?"

WHY IT HAPPENED:
────────────────
  P&L dashboard loads data when the page opens.
  It takes a "snapshot" of the database at that moment.
  
  When you change order status in Orders page:
  - Database is updated ✓
  - P&L page doesn't know about it ✗
  - P&L page shows OLD snapshot ✗
  
  Orders page and P&L page are SEPARATE files with NO communication.

UNDERSTANDING THE DATA:
──────────────────────

WHY ONLY "DELIVERED" ORDERS COUNT?
───────────────────────────────────

Revenue = Orders marked as DELIVERED

Order Status Pipeline:
  1. draft          → Not even confirmed yet
  2. confirmed  ← You create order here
  3. processing     → Picking from warehouse
  4. packed         → Ready to ship
  5. shipped        → In courier's hands (might get lost!)
  6. out_for_delivery → Delivery guy has it (might be returned)
  7. delivered  ← ONLY HERE counts revenue ✓
  
Why?
  📦 Until delivered, customer might:
    - Cancel order
    - Return package
    - Not pay
  
  ✅ Once delivered:
    - Customer has physical product
    - Can't be returned easily
    - Revenue is guaranteed
    - Can be counted in P&L

TROUBLESHOOTING:
────────────────

Problem: Refresh button not visible
Solution: 
  • Refresh browser page (Ctrl+Shift+R)
  • Make sure you're using latest version of profit-loss.html
  • Check top-right corner (next to Logout button)

Problem: Still shows ₹0 after refresh
Solution:
  • Check if order status is actually "delivered" (not just "shipped")
  • Go to Orders → Open order → Check Status History
  • Verify order is in same tenant (not different account)
  • Try refresh again (sometimes takes 2-3 seconds)

Problem: Revenue doesn't match
Solution:
  • Check filter dates (if filtered to specific month, recent orders might not show)
  • Make sure orders are marked as delivered (check Status History)
  • Verify order amounts are correct
  • Open browser console (F12) for any error messages

Problem: Refresh takes too long
Solution:
  • Check internet speed
  • Refresh again (first load might be slow)
  • If consistently slow, contact support
