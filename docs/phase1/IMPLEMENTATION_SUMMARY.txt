🔍 ERROR CODE FORMAT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Format: ERR-<unix_timestamp>-<4char_hash>

Example: ERR-1771677450-B631
         │   │             │
         │   │             └─ MD5 hash of error (first 4 chars, uppercase)
         │   └─ Unix timestamp (Feb 21, 10:30:50)
         └─ Always "ERR"

Properties:
✅ Unique - Each error gets unique code
✅ Sortable - Timestamp allows chronological ordering
✅ Reversible - Can parse to recover original timestamp
✅ Deterministic - Same error input = same hash
✅ Safe - No sensitive data exposed
✅ Short - Only 32 characters max
✅ Human-readable - Easy to share, type, search
✅ Collision-resistant - MD5 prevents duplicates

Lifespan: 6 hours (matches activity_logs TTL, then auto-deleted)
