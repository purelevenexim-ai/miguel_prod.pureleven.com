DATABASE
────────
New Fields (Lead table):
  • remind_date DATE
  • order_id UUID (FK to orders)
  • contacted_count INT
  • is_archived BOOL
  • note_last TEXT

New Table (lead_messages):
  • id, tenant_id, lead_id, direction, message_body, whatsapp_message_id, created_at

Updated Enums:
  • LeadPipelineStatus: created, new_lead, contacted, success, not_interested
  • LeadActivityType: + contacted_popup, recovery_campaign, message_received

BACKEND SERVICES
────────────────
New Functions:
  • mark_contacted() - Execute contacted popup action
  • finalize_success_won() - Convert lead to order+customer
  • get_reminded_leads() - Fetch today's reminders
  • get_lost_leads() - Fetch archived leads for recovery
  • store_whatsapp_message() - Save message history
  • send_recovery_campaign() - Bulk WhatsApp/email sender

New Routes:
  • POST /api/leads/{id}/contacted
  • POST /api/leads/{id}/success_won
  • GET /api/leads/reminded_today
  • GET /api/leads/lost_leads
  • GET/POST /api/leads/{id}/messages
  • POST /api/leads/bulk_campaign

New Module:
  • app/modules/whatsapp/ (Twilio/Meta API wrapper)

✨ KEY IMPROVEMENTS (Beyond Core Requirements)
═════════════════════════════════════════════════════════════════════════════

1. Smart Order Reuse
   When order created → check if phone in leads → reuse instead of duplicate

2. Auto-Reply on WhatsApp
   New WhatsApp lead → instant acknowledgment → professional impression

3. Bulk Recovery Campaigns
   Lost leads → send batch WhatsApp/email → re-engagement revenue stream

4. 48hr Inactivity Alert
   Contacted leads inactive 48h → 🔥 badge → forces follow-up

5. Never Delete Data
   Archive instead of delete → compliance + future re-engagement

6. Automation Jobs
   Nightly reminders → daily stats → weekly exports (zero manual work)

7. Performance Optimized
   Indexes on status, remind_date, is_archived → fast queries even at scale

8. Mobile First
   Full-screen chat on mobile → swipeable quick actions → staff loves it
