🎯 PAYMENT STATUS AUTO-INFERENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When user edits amount_paid:

  User sets amount_paid = 0:
    ├─ System checks: 0 >= total_amount? NO
    ├─ System checks: 0 > 0? NO
    └─ Inferred status = "pending" 💵

  User sets amount_paid = 200 (total is 480):
    ├─ System checks: 200 >= 480? NO
    ├─ System checks: 200 > 0? YES
    └─ Inferred status = "partial" 🔶

  User sets amount_paid = 480 (total is 480):
    ├─ System checks: 480 >= 480? YES
    └─ Inferred status = "paid" ✅

Note: If user manually sets payment_status in same PATCH request,
      the manual override takes precedence (highest priority)
