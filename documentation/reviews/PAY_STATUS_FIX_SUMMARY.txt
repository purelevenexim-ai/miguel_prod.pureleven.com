📋 ISSUE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When editing an order's "Amount Paid" field, the "Pay Status" dropdown was not
automatically updating to show the calculated status (Pending/Partial/Paid).

Example:
  • Order total: ₹500
  • You change Amount Paid: 0 → 250
  • You save the order
  • But Pay Status still showed "Pending" instead of "Partial" 🔶

Backend: ✅ CORRECT
  - service.py lines 831-838 already had correct auto-inference logic
  - When amount_paid changes, payment_status is recalculated
  - Server returns updated payment_status in response

Frontend: ❌ PROBLEM
  - No visual feedback during editing
  - User couldn't see what status SHOULD be
  - Had to save and reopen order to see change
  - No real-time calculation in the UI

    Status = "PENDING" 💵 (Amber)
