GITHUB SECRETS TO CONFIGURE
================================================================================

Before deployment works, add these secrets to GitHub:
Settings → Secrets and variables → Actions

For UAT Server:
  - UAT_SSH_HOST     (your UAT server IP)
  - UAT_SSH_USER     (SSH username, usually "root")
  - UAT_SSH_KEY      (contents of your private SSH key)

For Production Server:
  - PROD_SSH_HOST    (your Production server IP)
  - PROD_SSH_USER    (SSH username, usually "root")
  - PROD_SSH_KEY     (contents of your private SSH key)

================================================================================
TROUBLESHOOTING
================================================================================

Q: GitHub Actions won't deploy?
A: Check that SSH secrets are added to GitHub with correct format

Q: .env file missing?
A: cp .env.example .env && nano .env (fill in your values)

Q: Database migration failed?
A: docker logs crm-uat-backend (view error) or restore from backup

Q: Docker containers won't start?
A: Ensure all required variables in .env are filled in

Q: Secret is exposed?
A: GitHub will block the push automatically. Remove secret, commit, and push again.
