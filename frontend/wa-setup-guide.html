Get your WABIS API Token

REQUIRED

The API Token lets Miguel send WhatsApp messages directly from the chat inbox and audience section. It authenticates every request to bot.wabis.in/api/v1/.

1
Open bot.wabis.in and log in to your WABIS account.
2
In the top navigation bar click Developer.
3
You will see a section called Your API Tokens. Click Create New Token or copy an existing one.
4
Copy the full token string — it looks like:
API Token format 18280|Ws5wnHgkReob1OKVhDHWH3kzEIIRjItGN9wPcQFz23380f95
5
Keep this token safe — treat it like a password. You'll paste it in Step 3.
💡
Your token is: 18280|Ws5wnHgkReob1OKVhDHWH3kzEIIRjItGN9wPcQFz23380f95 — this is already filled in for you in the Settings page tip.
🌐 Open bot.wabis.in →
2

Get your WhatsApp Phone Number ID

REQUIRED

The Phone Number ID identifies which WhatsApp number should send messages. Every WABIS API call requires this alongside the API token.

1
In bot.wabis.in, go to WhatsApp Accounts (or My Numbers) in the sidebar.
2
Click on your WhatsApp number / account.
3
Look for the field labelled Phone Number ID or phone_number_id. It is a numeric ID (e.g. 521234567890123).
4
Copy this number. You'll paste it in Step 3.
⚠️
Phone Number ID ≠ Phone Number. The phone_number_id is a long numeric identifier assigned by Meta/WhatsApp. Your actual phone number (e.g. +91 94477 44583) is different from this ID.
3

Paste credentials into Miguel Settings

REQUIRED
1
In Miguel, open Marketing → ⚙️ Settings.
2
Find the WhatsApp — WABIS Setup section.
3
In the API Token field — paste the token from Step 1. The field is masked (password type) — that is normal.
4
In the Phone Number ID field — paste the ID from Step 2.
5
Click 💾 Save Settings. You should see a green ✅ success banner.
ℹ️
The Bot ID and Access Token under "Legacy / Workflow URL settings" are only needed if you use WABIS Workflow URLs for order notifications. They are not required for direct messaging from the chat inbox.
4

Configure Inbound Webhook in WABIS

AUTO-GENERATED

The inbound webhook lets WABIS notify Miguel when a customer sends you a WhatsApp message. Without this, you will not receive incoming messages in the inbox.

1
In Miguel → Settings → find the Inbound Webhook section. Your unique webhook URL is shown there — it looks like:
Webhook URL https://yourdomain.com/api/wa/inbound/{your-tenant-id}
Webhook Secret Click 👁 to reveal in Settings
2
Copy the Webhook URL (click the 📋 copy button next to it).
3
Go to bot.wabis.in → your WhatsApp Account → Webhook Settings (or Outbound Webhook).
4
Paste Miguel's webhook URL as the Webhook URL.
5
Add a custom header:
Header name: X-Webhook-Secret
Header value: copy the secret from Miguel (click 👁 to reveal it).
6
Enable the events: Message Received and Button/Postback. Save in WABIS.
💡
Once the webhook is configured, every message your customers send on WhatsApp will appear in Miguel's 💬 Inbox tab in real time.
5

Test the Connection

VERIFY
1
After saving your API Token + Phone Number ID, scroll to the top of the WhatsApp — WABIS Setup section.
2
Click the 🔌 Test Connection button.
3
You should see: ✅ Connection successful
The status badge at the top will show ✅ Ready — Direct Messaging Enabled.

What to do if it fails:

401 Unauthorized API Token is wrong or expired — re-copy from WABIS Developer page
404 Not Found Phone Number ID is incorrect — re-copy from WABIS WhatsApp Accounts
Cannot reach server Check internet connection or WABIS service status
Not Configured badge API Token or Phone Number ID is empty — make sure you saved
6

Set Up Order Notification Messages

OPTIONAL

Miguel can automatically send a WhatsApp message when an order status changes (e.g. confirmed, packed, shipped, delivered). Each trigger uses a WABIS Workflow URL.

1
In bot.wabis.in → go to Automations or Flows / Workflows.
2
Create or open a workflow (e.g. "Order Confirmed Message"). Design the WhatsApp template message with your variables. In WABIS, at the top of the workflow you will see a Webhook URL — copy it.
3
In Miguel → Settings → scroll to Campaign Types / Message Templates. Click + Add Template.
4
Fill in:
Namee.g. "Order Confirmed WA"
Trigger EventOrder → Confirmed
Workflow URLPaste the WABIS webhook URL from step 2
5
In the Payload Template JSON, use these available variables:
{{customer_name}}Customer's full name
{{order_number}}Order reference number
{{tracking_number}}Courier tracking number
{{courier_name}}Courier company name
{{total_amount}}Order total amount
{{phone}}Customer phone (auto-set)
6
Save the template. Now whenever an order is moved to Confirmed status, Miguel automatically sends the WhatsApp message to that customer.
⚠️
24-hour window: WhatsApp only allows free messages within 24 hours of a customer's last message. For order notifications initiated by you (outside the 24h window), Miguel uses approved Utility templates automatically. Set up a Utility template workflow URL in the Campaign Type for Order Created.
7

Set Up Postback / Button Rules

OPTIONAL

When a customer taps a quick-reply button in WhatsApp, WABIS sends a postback event to your webhook. Postback Rules tell Miguel what to do automatically when that happens.

1
In Miguel → Settings → Postback Rules section → click + Add Rule.
2
Keyword: The exact postback value WABIS sends (from your WABIS button config, e.g. BTN_CONFIRM_ORDER or INTERESTED).
3
Action: What Miguel should do:
Tag subscriberAdd a label to this subscriber in the inbox
Change WA statusUpdate their conversation status (e.g. Contacted, Won)
Trigger campaignStart a blast / workflow for this subscriber
4
Save the rule. It becomes active immediately — the next time a customer taps that button, Miguel executes the action automatically.
💡
Use postback rules to auto-qualify leads. For example: when a customer taps "I want to buy", automatically change their status to Interested and add a Hot Lead tag.
