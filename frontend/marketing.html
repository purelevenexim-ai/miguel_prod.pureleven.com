Quick Setup Checklist
Everything you need to get WhatsApp messaging fully working. Collect these values, then paste them in the sections below.
⬜ WABIS API Token REQUIRED
1. Go to bot.wabis.in
2. Login → click Developer (top menu)
3. Copy your API Key
4. Paste in API Token field below ↓
⬜ WhatsApp Phone Number ID REQUIRED
1. In WABIS → WhatsApp Accounts
2. Click your phone number
3. Find phone_number_id
4. Paste in Phone Number ID field below ↓
⬜ Inbound Webhook URL AUTO
1. See your webhook URL in Inbound Webhook section below ↓
2. In WABIS → Webhooks → paste this URL
3. Enable "Message Received" + "Postback" events
4. Save in WABIS
⬜ Bot ID + Access Token OPTIONAL
Only needed for workflow/order notification triggers.
1. In WABIS → Bots → copy Bot ID
2. In WABIS → Developer → copy Access Token
3. Paste in Legacy settings section below ↓
⬜ Order Notification Workflow URLs OPTIONAL
For auto-sending WA messages on orders.
1. In WABIS → Automations / Workflows
2. Copy webhook URL for each flow
3. Paste in Campaign Types section below ↓
⬜ Test Connection FINAL STEP
After filling in your API Token + Phone Number ID:
1. Click 💾 Save Settings below
2. Click 🔌 Test Connection
3. You should see ✅ Connection successful
